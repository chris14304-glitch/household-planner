# Household Planner

A household management application designed to help organize schedules, coordinate household activities, and plan meals in one convenient place.

## Live Application

**[Launch Household Planner](https://household-planner-lime.vercel.app/)**

## Features

- **Household Scheduling:** Organize and manage household schedules and activities.
- **Meal Planning:** Plan meals and keep household meal organization in one place.
- **Supabase Integration:** Connects to Supabase for backend data services.
- **Centralized Organization:** Brings household planning and scheduling together in a single application.
- **Web-Based Access:** Access the application through its deployed website.

## Technology

- **Supabase:** Backend service integration.
- **Vercel:** Application deployment and hosting.

## Purpose

The goal of this project is to make everyday household management easier by combining scheduling, planning, and meal organization into one application.

This project demonstrates practical application development, backend service integration, and the development of a web-based tool designed to solve everyday problems.
